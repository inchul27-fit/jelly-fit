# 젤리핏 간판 QR 랜딩 페이지

## 시안 확인

`index.html`을 Chrome 또는 Edge에서 열면 됩니다. 모바일 화면은 개발자 도구의 기기 모드(`Ctrl+Shift+M`)에서 확인할 수 있습니다. 설치나 빌드가 필요 없습니다.

## 연락처와 위치 수정

카카오톡 1:1 채팅 주소, 전화번호, 네이버 플레이스·블로그 주소, 도로명 주소, 입구 설명과 사진은 모두 `index.html`에 직접 적혀 있습니다. JS를 실행하지 않는 AI 수집기도 링크와 사진을 읽을 수 있게 하기 위해서입니다. 버튼 링크는 `<a id="kakao">`, `<a id="phone">`, `<a id="place">`, `<a id="blog">`의 `href`를 고칩니다. 전화번호·주소·운영시간을 바꿀 때는 센터 정보, 자주 묻는 질문, `<head>`의 JSON-LD도 함께 고칩니다. 이미지 파일은 `assets/`에 둡니다.

전화번호와 도로명 주소는 젤리핏 간판 작업지시서를 반영했습니다. 입구 사진은 간판 교체 후 촬영한 정면 유리문 계단 입구 사진입니다. 입구 모습이 바뀌면 사진과 설명을 함께 갱신하세요.

## 공개 주소와 배포

간판 QR의 고정 주소는 **https://inchul27-fit.github.io/jelly-fit/** 입니다. 저장소 이름, GitHub 소유자와 공개 경로를 유지합니다. `main` 브랜치 루트의 파일을 수정하면 GitHub Pages가 같은 주소로 배포합니다. `style.css`나 `site.js`를 수정할 때는 `index.html`의 `?v=...` 버전도 갱신합니다.


## AI·검색 노출 정보 (구조화 데이터)

`index.html`의 `<head>`에 검색 결과·SNS 공유용 정보(title, description, canonical, Open Graph)와 schema.org JSON-LD 두 개(`ExerciseGym`/`HealthClub` 센터 정보, `FAQPage` 자주 묻는 질문)가 있습니다. 주소, 전화, 운영시간, FAQ 문구를 바꿀 때는 블로그 버튼 아래 **센터 정보**·**자주 묻는 질문** 펼침 버튼 내용과 JSON-LD를 함께 같은 글자로 고칩니다. 가격·할인·이벤트 문구는 넣지 않고 카카오톡·전화 상담으로 안내합니다.

`sitemap.xml`은 페이지를 수정해 배포할 때 `<lastmod>` 날짜를 갱신합니다. GitHub Pages 프로젝트 사이트는 도메인 루트의 `robots.txt`를 둘 수 없으므로, 사이트맵은 Google Search Console·네이버 서치어드바이저에 직접 제출합니다.

## 관리자용 접속 통계

Google Analytics 4 측정 ID는 `G-EQTSNH6LLK`입니다. `index.html`에서 Google 태그를 한 번 불러와 페이지 조회를 수집하고, `site.js`에서 아래 버튼 클릭 이벤트를 보냅니다. Google Signals와 광고 개인 최적화 신호는 사용하지 않습니다. 페이지에 방문자 수를 공개 표시하지 않습니다.

| 버튼 | 이벤트 이름 |
| --- | --- |
| 카카오톡 상담 | `카카오톡_상담_클릭` |
| 전화 문의 | `전화_문의_클릭` |
| 시설 사진 · 위치 | `시설사진_위치_클릭` |
| 블로그 | `블로그_클릭` |
| 센터 정보 펼치기 | `센터정보_열기` |
| 자주 묻는 질문 펼치기 | `FAQ_열기` |

한글 이름은 변경 배포 이후 클릭부터 적용됩니다. 이전 영어 이름(`kakao_click`, `phone_click`, `naver_place_click`, `blog_click`)으로 수집된 기록은 기존 이름으로 남습니다. 배포 전부터 페이지를 열어 둔 방문자는 새로고침 전까지 이전 이름으로 기록될 수 있습니다. 변경 전후 기간을 함께 비교할 때는 두 이름의 클릭 수를 함께 봅니다.

GA4가 자동 수집하는 `first_visit`(첫 방문), `page_view`(페이지 조회), `session_start`(방문 시작)는 기본 이름을 유지합니다.

[Google Analytics](https://analytics.google.com/)에서 젤리핏 속성을 선택합니다.

- **실시간 보고서:** 배포 후 휴대폰으로 랜딩 페이지에 접속하고 버튼을 눌러 방문과 이벤트 수신을 확인합니다.
- **보고서 → 참여도 → 페이지 및 화면:** 날짜 범위를 하루로 선택하면 일일 조회수, 수집 시작일부터 선택하면 누적 조회수를 확인할 수 있습니다. 메뉴가 보이지 않으면 보고서 검색을 이용합니다.
- **이벤트 보고서:** 위 이름으로 각 버튼의 클릭 수를 확인합니다. 클릭 수는 실제 상담 완료나 등록 건수를 의미하지 않습니다.

날짜 경계는 GA4 속성의 보고 시간대(대한민국)를 따릅니다. 조회수는 같은 사람의 재방문·새로고침도 포함하므로 방문자 수와 구분합니다. 고유 방문자 수를 기간별로 볼 때는 해당 기간의 사용자 수를 사용하며 일별 사용자 수를 합산하지 않습니다. 통계는 설치 이후부터 쌓이고, 일반 보고서 반영에는 보통 24~48시간이 걸릴 수 있습니다. 광고 차단 등으로 일부 방문이 집계되지 않을 수 있습니다.
